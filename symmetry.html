Symmetry

Symmetry is a SaaS AI tool that captures and surfaces LLM-generated work knowledge through a conversational chat agent, available across Chrome extension, web dashboard, and desktop app.

Overview

Joined as employee #4, inheriting an engineering prototype with no brand, no design system, and no process. Defined all three from scratch across four platforms simultaneously.

Designed the core AI chat interface, passive injection via Chrome extension, active retrieval through the web dashboard, and a persistent desktop agent, navigating the tension between deterministic and probabilistic knowledge surfacing across surfaces.
